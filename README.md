# 🎮 Fun Game Projects

Welcome to the **Game Projects** folder! Here you will find simple and fun games made with Python, Java, and Web technology (HTML/CSS/JS).

These games are easy to play and great for learning how games are built.

---

## 🕹️ Our Games

### 1. Dodge the Blocks (Python)
In this game, you control a blue square. Red blocks fall from the top, and you must move left or right to avoid them!

- **How to Play**:
  - Use the **Left Arrow Key** to move left.
  - Use the **Right Arrow Key** to move right.
  - Don't let the red blocks touch you!
- **Requirements**: You need **Python** and the **Pygame** library installed.
- **Run it**: `python Blockgame.py`

### 2. Chess: Grandmaster Edition (Web)
A classic game of Chess that you can play right in your web browser. It has a beautiful design and works smoothly.

- **How to Play**:
  - Open the file in your browser.
  - Choose your side (White or Black).
  - Click on a piece and then click on a square to move it.
- **Requirements**: Any modern web browser (Chrome, Edge, etc.).
- **Run it**: Double-click on `chessgame.html`.

### 3. Dodge the Blocks (Java)
This is a Java version of the "Dodge the Blocks" game. It uses a window-based interface called Swing.

- **How to Play**:
  - Use your keyboard to move the player.
  - Avoid the falling obstacles to keep your score going up.
- **Requirements**: You need **Java (JDK)** installed.
- **Run it**:
  - Compile: `javac DodgeTheBlocks.java`
  - Run: `java DodgeTheBlocks`

## 📂 What's inside this folder?

- **`Blockgame.py`**: The Python game code.
- **`DodgeTheBlocks.java`**: The Java game code.

- **`stylechess.css` & `stylechess.js`**: Files that make the Chess game look good and work correctly.
